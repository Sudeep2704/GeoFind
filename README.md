## ✨ About GeoFind

**GeoFind** is a location-based talent discovery web application that helps users find and connect with professionals in their city.  
It combines **interactive maps**, **clean profile cards**, and **powerful search & filters** to make discovering nearby talent simple and intuitive.

Whether you are a recruiter, startup founder, or student looking for collaborators, GeoFind helps you discover the right people faster.

---

## 🚀 Features

- 🔍 **Search & Filter**  
  Find professionals by name, skill, or city

- 🗺️ **Interactive Map**  
  View talent locations using OpenStreetMap and Leaflet

- ❤️ **Like Profiles**  
  Save your favorite profiles for quick access

- 👑 **Admin Dashboard**  
  Add, edit, or remove professional profiles

- 📱 **Responsive Design**  
  Works seamlessly on desktop and mobile devices

- ⚡ **Fast & Modern UI**  
  Built with React and Material UI
